# HIVE — Project Source Pack

## Purpose

This package is the canonical source set for the HIVE project inside ChatGPT Projects.

HIVE is a local-first context, memory, retrieval, token-efficiency and orchestration platform for large software projects built with LLM executors.

The intended operating model is:

**Sol = architect, specifier, auditor and reviewer.**  
**Executor LLM = implement, test and correct.**  
**Tests = objective evidence.**  
**Checkpoint = source of current execution truth.**
