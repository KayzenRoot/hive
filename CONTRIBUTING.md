# Contributing to HIVE

HIVE is developed in small, auditable increments. Before changing code, read
AGENTS.md and the canonical sources in docs/project-brain/.

Use a focused branch and pull request. Include the motivation, scope, validation
commands, and any known risks. Keep the main branch protected and do not merge
changes that bypass the project review workflow.

No open-source license has been selected yet; contribution terms remain subject
to the repository owner's later decision.
