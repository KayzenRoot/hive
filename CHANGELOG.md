## [1.0.0] - 2026-09-17

First stable professional distribution of the product baseline accepted as
HIVE V0.1 — Foundation. Release engineering only: no product capability was
added, and the accepted V0.1 closure evidence is unchanged.

### Added

- Professional maintenance documentation: `docs/VERSIONING.md`,
  `docs/MAINTENANCE.md`, rewritten `docs/UPGRADING.md`,
  `docs/RELEASE-CHECKLIST.md` and `docs/releases/` policy, template and notes.
- `scripts/verify_release_metadata.py`, a deterministic release metadata
  verifier integrated into `scripts/validate.py` and therefore into the hosted
  Validate gate.
- Machine-readable release manifest (version, tag, source commit, artifact
  name/size/SHA256, migration head, canonical product baseline) generated by
  `scripts/prepare_release.py`.
- Annotated-tag identity checks, exact tag/VERSION/notes/CHANGELOG coherence,
  required-file and forbidden-path enforcement and manifest attachment in
  `.github/workflows/release.yml`.
- CodeQL (Python, JavaScript/TypeScript) and Dependency Review workflows as
  advisory security automation.
- Weekly grouped Dependabot configuration for pip, npm and GitHub Actions.
- Professional issue and pull request templates, and an All Rights Reserved
  `LICENSE` notice.
- Release-candidate provenance receipt under `.engineering/release/` recording
  the immutable V0.1 closure lineage.

### Changed

- Active distribution and runtime identity promoted from `0.0.1-bootstrap` to
  `1.0.0` across `VERSION`, backend runtime surfaces and dashboard package
  metadata, with regression coverage.
- README rewritten as the stable release landing page with current,
  evidence-backed capabilities.
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` and `AGENTS.md` aligned with
  the production maintenance lifecycle.
- Dependabot cadence changed from monthly to weekly grouped updates; dependency
  PRs still require normal review and are never auto-merged.

### Fixed

- Release packaging now requires the stable release file set (CHANGELOG,
  LICENSE, upgrading/versioning documentation, Dockerfiles, lockfiles) and fails
  closed on missing files, version mismatch, missing release notes and forbidden
  secret/local/user content.

### Security

- Remediated all 16 open HIGH Dependabot advisories affecting the candidate by
  pinning patched versions in `requirements.txt`: `fastapi==0.133.0` (required
  to allow the patched `starlette==1.3.1`), `python-multipart==0.0.31` and
  `Mako==1.3.12`. The compatible `sse-starlette` and `mcp` pins already accept
  the patched Starlette line; the full backend suite and integration health
  verify the transition.
- CodeQL and Dependency Review added without weakening `scripts/check_secrets.py`,
  the Validate/Integration health/Review Evidence gates or ruleset 21934284.
- Remaining open dependency alerts are three MEDIUM development-only advisories
  (`vitest`, `@vitest/mocker`, `pytest`), documented in
  `.engineering/release/HIVE-V1.0.0-SECURITY-TRIAGE.json`; no LOW alerts remain.
- No secrets, credentials, private keys, `.env` files or user runtime data are
  included in the release diff or package.

### Assurance

- Focused tests fail closed on version drift, missing or duplicate
  changelog/release-note metadata, missing required files, forbidden content and
  checksum determinism.
- `HIVE-REL-001` is registered in Review Evidence governance with an exact
  authorized base and a bounded release-engineering scope.

## 0.0.1-bootstrap - Released 2026-08-31

The bootstrap foundation was published as the GitHub pre-release
`v0.0.1-bootstrap` after protected squash merge, post-merge CI, release
workflow validation, and independent asset checksum verification.
